Token Lens

Same MCP server. Same question. Two ways for the model to use it, and what each costs in tokens.

Simulated mode: no GEMINI_API_KEY set, so token counts are estimates (characters ÷ 4). Use this for rehearsal only.

Direct MCP

The model calls each MCP tool itself. Every tool result is added to the conversation, and the whole conversation is sent again on every call.

Code mode

The model writes one script. The script calls the same MCP tools inside a sandbox, and only its small result goes back to the model.
